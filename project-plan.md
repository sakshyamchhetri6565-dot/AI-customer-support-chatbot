# AI-Powered Customer Support Chatbot — Project Plan

 1. Project Overview
The project aims to plan and develop an AI-powered chatbot that helps automate customer support by answering common questions quickly and consistently.

 2. Project Objectives
- Automate responses to frequently asked questions.
- Improve customer response times.
- Reduce the workload of customer support staff.
- Provide consistent and accessible customer support.

3. Project Scope
 In Scope
- Gather and document requirements.
- Plan the chatbot conversation flow.
- Research suitable AI technologies.
- Design the user interface.
- Prepare testing and quality plans.
- Maintain project documentation.

Out of Scope
- Production deployment unless approved.
- Integrations with live customer databases unless approved.
- Features not agreed upon in the project scope.

 4. Key Deliverables
- Project requirements and scope.
- Chatbot conversation flow.
- Technology research.
- User interface design.
- Testing plan.
- Project documentation and final report.

 5. Project Schedule
The project schedule will be finalised according to the assessment deadline and the group's agreed plan. Task progress will be tracked through GitHub Issues and the project board.

 6. Risk Management
Potential risks include delays, unclear requirements, unsuitable AI responses, technical difficulties, and limited time. These risks will be monitored and addressed through planning, testing, and regular progress reviews.

 7. Configuration Management
GitHub will be used to store project documentation, record changes through commits, and track tasks using Issues and Projects.

## 8. Project Status
Planning and documentation are in progress.
